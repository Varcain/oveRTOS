# LVGL binding parity whitelist
#
# Each non-comment line is `binding type method` (snake_case): an
# intentional or tracked gap the parity checker should not fail on.
# A trailing `# ...` comment carries the per-gap rationale.  The
# checker's staleness guard fails --strict if a line here no longer
# names a real only-in-one-binding gap, so this file tracks reality.
#
# Bootstrapped from a per-method source triage of all three bindings;
# hand-maintained thereafter — when a new gap appears, either fix it in
# the binding or add a line here with a rationale.
