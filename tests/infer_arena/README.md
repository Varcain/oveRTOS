# Trusted-model arena checks

`make test-infer-admission` and `make test-infer-admission-sanitize` execute this
suite and its safe mutations in both allocation modes alongside admission tests.
For a direct run, configure `tests/infer_admission` with `OVE_ARENA_MUTATIONS=ON`, build it, then
run `python3 tests/infer_arena/run.py <build> --mutations`. Repeat with
`OVE_ZERO_HEAP=ON`, `OVE_SANITIZE=ON`, and both, passing the corresponding
`--zero-heap` and `--sanitize` flags. Run the existing admission runner too.

The allocator tests use the real pinned library. The overlap control compares
addresses inside allocated backing without using overlapping storage. Planner
checks stop at offset retrieval and never publish out-of-range tensor pointers.
The frontier tests replace the arena factory with a stop: omitted model checks
or zeroing fail an assertion before SDK placement or teardown. Mutation results
must be ordinary assertion failures; sanitizer findings and timeouts are errors.
The zeroing mutation is intentionally tested at this stop, while an actual
initialized, structurally valid unregistered-op model proves clean fixed teardown.

The model tests use original aligned sine and keyword assets. They measure a
large, successfully initialized arena, recording persistent usage, preparation
head peak before planner scratch, planner scratch prefix and actual entry count.
One aligned candidate is derived strictly above persistent usage plus all those
preparation requirements and an alignment margin, and below both total usage and
the plan admission limit. An empty interval stops the test; no sizes are probed.
No malformed model or undefined small-arena kernel path is executed. The tiny
sweep ends below the first checked scratch reservation and includes all front
alignment residues. Queries include raw front padding; heap backing is released
before assertions about recorded scalar results.

Observer macros add calls only in the fixture translation unit. They add no
fields or allocations and are absent from production builds. The fixtures use
`TF_LITE_STATIC_MEMORY` and the same C++ ABI options as the library. Keyword data
is regenerated by the normal model converter. The test-only mutation generator
writes exact single-change adapters inside the build workspace; SDK and product
files stay unchanged.
